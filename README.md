# CinePrompt Rig

A visual PWA for creating cinematic camera and video prompts. It works locally in the browser and keeps reference images on-device.

## Features

- visual camera orbit and coverage angles;
- cinema camera, sensor, lens, focal length, aperture and anamorphic controls;
- photorealistic English prompt generation;
- Camera A/B/C/D coverage and consistent character/location references;
- multi-shot video editor for Seedance 2.0/2.5, KLING 3.0 and Google Omni;
- installable PWA.
